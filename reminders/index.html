Pense-Bête Développeur & SysAdmin

📁 Fichiers & Dossiers

  • ls -laLister tous les fichiers (détaillé)
  • cd ..Remonter d'un niveau
  • pwdDossier courant
  • mkdir dossierCréer un dossier
  • cp source destCopier
  • mv source destDéplacer / Renommer
  • rm -rf dossierSupprimer récursivement

🔒 Permissions

  • chmod 755 fileModifier les droits
  • chown user:fileChanger le propriétaire
  • umaskMasque par défaut

⚙️ Processus & Système

  • ps auxVoir les processus
  • htopMoniteur interactif
  • kill PIDTerminer un process
  • df -hEspace disque
  • free -hMémoire RAM
  • uname -aInfos noyau

🌐 Réseau & Paquets

  • ip aAdresses IP
  • ping hostTester connectivité
  • netstat -tulnPorts d'écoute
  • sudo apt updateMettre à jour les sources
  • sudo apt install pkgInstaller un paquet

🔍 Recherche & Texte

  • find / -name fileRechercher un fichier
  • grep "mot" fileChercher du texte
  • cat fileAfficher un fichier
  • tail -f fileSuivre les logs en direct

📦 Archives (TAR & Zip)

  • tar -czf archive.tar.gz dirCréer une archive tar.gz
  • tar -xzf archive.tar.gzExtraire une archive tar.gz
  • tar -cjf archive.tar.bz2 dirCréer une archive tar.bz2
  • tar -xjf archive.tar.bz2Extraire une archive tar.bz2
  • tar -tf archive.tar.gzLister le contenu sans l'extraire
  • tar -xzf arc.tar.gz -C /repExtraire dans un dossier précis
  • zip file.zip dirCréer un zip
  • unzip file.zipExtraire un zip

⚡ Find + Exec & Xargs

  • find . -name "*.log" -exec rm {} \;Supprimer via find
  • find . -type f -exec chmod 644 {} +Changer droits en masse
  • cat list.txt | xargs -I {} cp {} /destCopier une liste
  • find . -name "*.txt" | xargs grep "mot"Recherche combinée

⚡ Bases & Syntaxe

  • #!/bin/bashShebang (première ligne)
  • echo "texte"Afficher un message
  • nom="Valeur"Déclarer une variable
  • echo $nomLire une variable
  • read -p "Msg: " varSaisie utilisateur

🔄 Conditions (If / Else)

  • if [ $a == $b ]; then ... fiÉgalité chaîne
  • if [ $a -eq $b ]; then ... fiÉgalité nombre
  • if [ -f "file" ]; then ... fiSi le fichier existe
  • if [ -d "dir" ]; then ... fiSi le dossier existe

🔁 Boucles

  • for i in 1 2 3; do ... doneBoucle For simple
  • for f in *.txt; do ... doneBoucle sur fichiers
  • while [ $n -le 5 ]; do ... doneBoucle While

🛠️ Fonctions & Arguments

  • ma_fonction() { ... }Déclaration de fonction
  • $1, $2, ...Arguments du script / fonction
  • $#Nombre d'arguments
  • $?Code de retour dernière commande

🐍 Variables & I/O

  • print("Hello")Afficher dans la console
  • x = 5 / name = "Alice"Variables
  • input("Nom ? ")Saisie utilisateur
  • f"Nom: {name}"F-string (interpolation)

🔀 Conditions

  • if x > 0: ...Condition simple
  • elif x == 0: ...Sinon si
  • else: ...Sinon
  • and, or, notOpérateurs logiques

🔄 Boucles & Listes

  • for i in range(5): ...Boucle For (0 à 4)
  • for item in ma_liste: ...Parcourir une liste
  • while x < 10: ...Boucle While
  • ma_liste.append(val)Ajouter à une liste

📦 Fonctions & Fichiers

  • def ma_fonc(param): ...Définir une fonction
  • import mathImporter un module
  • open("file.txt", "r")Ouvrir un fichier en lecture
  • with open(...) as f:Gestion propre de fichier

🌐 Serveur Web & Outils

  • python3 -m http.server 8080Serveur sur le port 8080
  • python3 -m http.server 80 --bind IPServeur sur IP et port
  • python3 -m http.server 8080 -d /pathServeur avec chemin cible
